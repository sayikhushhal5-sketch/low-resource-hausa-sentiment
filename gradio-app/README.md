# Low-Resource Hausa Sentiment Classifier

Three-class sentiment classifier (negative / neutral / positive) for Hausa
text, built on `xlm-roberta-base` fine-tuned on AfriSenti Hausa.

**Model:** https://huggingface.co/sayikhushhal/xlm-r-hausa-sentiment
